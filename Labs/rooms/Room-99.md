### THE EXIT EXAM!

<ol class="tasks">

</ol>
This room tests your knowledge of the Linux commands you've used throughout
the escape rooms.

    1. Run `./getKey.sh` to start the quiz.
    2. Answer all **5 questions** correctly.
    3. Questions are selected **randomly** from a pool each time.
    4. One wrong answer and you must start over!
    5. Answer all correctly to receive the final password.

### Topics Covered

| Category            | Examples                                                |
| ------------------- | ------------------------------------------------------- |
| File & Directory    | `find`, `ls`, `cat`, `grep`, `wc`, `sort`, `uniq`       |
| Text Processing     | `sed`, `awk`, `tr`, `cut`, `tac`, `rev`, `head`, `tail` |
| Archives            | `tar`, `gzip`, `base64`                                 |
| System & Processes  | `ps`, `kill`, `chmod`, `chown`, `export`, `alias`       |
| Symbols & Operators | `\|`, `>>`, `&&`, `~`, `#`                              |

### How to Run

```bash
./getKey.sh
```


!!! tip "Hint 1"
Each answer is the **exact command name** (or symbol) -case-sensitive,
no spaces.

!!! tip "Hint 2"
The question tells you the character count: e.g., _(4 chars)_ means the
answer is 4 characters long.

!!! tip "Hint 3"
Think back through all the commands you used in Rooms 01-12!
